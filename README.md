# FocusTask

WPF-приложение для фокус-сессий: задаёшь задачу, выбираешь приложения для блокировки и работаешь без отвлечений, пока идёт таймер.

## Возможности

- Создание фокус-сессии с задачей и ограничением по времени
- Выбор установленных приложений, которые нужно заблокировать
- Заблокированные приложения автоматически закрываются, пока идёт таймер
- Окно с уведомлением, когда сессия завершена

## Технологии

- C#, WPF
- .NET Framework 4.8
- Только Windows

## Запуск

1. Клонируй репозиторий:
```
   git clone https://github.com/xzqkut/TaskManager.git
```
2. Открой `TaskManager.slnx` в Visual Studio 2022 или новее
3. Нажми `F5`, проект соберётся и запустится

## Планы

- Перевод на современный .NET
- История задач и сессий
- Локальный клиент + API на ASP.NET Core с PostgreSQL
